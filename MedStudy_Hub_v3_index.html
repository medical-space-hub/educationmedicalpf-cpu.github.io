AI File Import Studio

استيراد الأسئلة والبطاقات والاختبارات من ملفاتك، مع مراجعة النتائج قبل النشر.

1. الملف المصدر

يدعم الاستيراد المحلي CSV وExcel (XLSX/XLS) مع معاينة الصفوف. يمكن اختيار PDF وWord وPowerPoint، لكن تحليلها بالذكاء الاصطناعي يحتاج خدمة معالجة ملفات متصلة؛ لا تُنشأ نتائج وهمية.

لم يُحدد ملف بعد. لا يتم رفع أي ملف إلى Supabase من هذه الواجهة تلقائيًا.

2. مراجعة المحتوى المستخرج

تحقق من السؤال والخيارات والإجابة والتكرارات قبل اعتماد المحتوى. أي إجابة ناقصة أو غير مؤكدة تتطلب مراجعة بشرية.

لا توجد معاينة بعد.

DraftValidationReviewPublish

Owner وAdmin يستطيعان إدارة المواد والموضوعات والمحتوى داخل المراكز الموجودة. إنشاء المراكز الرئيسية وتعديل الهوية والصلاحيات للـOwner فقط. النشر السحابي يتطلب تكامل API وRLS مفعلين؛ هذه المعاينة لا تتجاوز تلك الضوابط.
